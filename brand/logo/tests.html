Logo test sheet

The logo is the name set in the website's display font and stacked on two lines: Abdelfattah over Aboulfoutoh, left-aligned, tight leading. The AM badge and favicon use the same font. Everything is one flat shape in one colour. Regenerate with node brand/build-logo.mjs. Currently set in Tajawal Bold (the font that is bundled); once Satoshi is added the script uses it.

2 · Small sizes wordmark ≥ 26 px tall tight below ~22 px 16×16 favicon at 1× is soft 32 px crisp

The site header uses the wordmark at 34 px tall (26 px on phones). Below about 22 px tall the two lines (each ≈ 8 px high) start to crowd; use the AM badge or favicon there. The “AM” favicon is only ≈ 12 px wide on a 16×16 tab icon, so on a non-retina screen it reads as two soft letters (still recognisable); it is crisp at 32 px, which is what most screens use. A hand pixel-hinted 16×16 would be sharper.
